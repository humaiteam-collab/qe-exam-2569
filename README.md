# ระบบสอบ QE คุณสมบัติ (QE-2569)

เว็บแอปหน้าสอบสำหรับนิสิต เปิดใช้ผ่าน GitHub Pages ได้โดยตรง ไม่ต้องล็อกอิน กรอกรหัสนิสิต 10 หลักเพื่อเข้าสอบ

- หน้าสอบ: เปิดจากรากของไซต์นี้ (นิสิตต้องอ่านแนวทางการสอบและติ๊กยืนยันก่อนเข้าห้องสอบ)
- แอดมิน: `#admin` — เลือกโจทย์จากคลังข้อสอบ (หมวดละ 1 ข้อ) ตั้งเวลา แก้แนวทางการสอบ แล้วกด **เผยแพร่**
- กรรมการ: `#grade` — อ่านคำตอบและไฟล์แนบจากชีต ให้คะแนนตามรูบริก นำเข้าคำตอบที่เขียนด้วยมือ
- ใช้ได้บนคอมพิวเตอร์หรือแท็บเล็ต

## หลังบ้าน (Google Apps Script)

โค้ดอยู่ที่ `Code.gs` ผูกกับ Google Sheet "QE-2569"

| แท็บในชีต | เก็บอะไร |
|---|---|
| ชีต1 | คำตอบของนิสิต (ออนไลน์และเขียนด้วยมือ) |
| คะแนน | คะแนนจากกรรมการ |
| ไฟล์แนบ | รายการไฟล์ที่อัปโหลด (ตัวไฟล์อยู่ใน Google Drive โฟลเดอร์ "QE-2569 ไฟล์แนบคำตอบ") |
| ตั้งค่า (ซ่อน) | การตั้งค่าที่แอดมินเผยแพร่ |

### ติดตั้ง / อัปเดต

1. เปิดชีต QE-2569 → ส่วนขยาย → Apps Script
2. วางโค้ดจาก `Code.gs` แทนโค้ดเดิมทั้งหมด แล้วบันทึก
3. ตรวจว่า Project Settings → Script properties มี `ADMIN_KEY` (ใช้ค่าเดิมได้)
4. เลือกฟังก์ชัน `setup` แล้วกด Run หนึ่งครั้ง และอนุญาตสิทธิ์ Google Drive
5. Deploy → Manage deployments → แก้ไข deployment เดิม → Version: **New version** → Deploy
   (แก้ deployment เดิมเพื่อให้ URL เหมือนเดิม ไม่ต้องแก้ `APPS_SCRIPT_URL` ใน `index.html`)
